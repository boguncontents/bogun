AI 20명 동시접속 테스트

아이패드 20대 없이 PC 한 대에서 게임의 Cloudflare Worker로 실제 요청을 보내 응답 속도와 오류를 점검합니다.

1. 테스트 준비

테스트 버튼을 누르면 실제 AI API 요청이 발생하며 소액의 사용량·비용이 발생할 수 있습니다. 본인이 관리하는 주소에서만 실행하세요. 자동 반복·무한 재시도는 하지 않습니다.

추천 순서: 1명 성공 → 5명 성공 → 20명. 20명 테스트는 8개 대화 장면을 섞어, 한 번에 20개의 요청을 보냅니다.

2. 검사 결과

아직 테스트하지 않았어요. 위의 동의 체크 후 ‘1명 연결 확인’부터 시작해 주세요.

오류가 나면 어떻게 확인하나요?

HTTP 429는 요청 제한, 500/502/503/504는 서버 쪽 오류 가능성이 있습니다. 시간초과는 12초 안에 응답하지 못한 경우입니다. “네트워크/CORS 오류”는 인터넷, Worker 또는 웹페이지 출처 허용 정책과 관련 있을 수 있습니다.

이 페이지를 PC에서 파일로 직접 열어 실행하면 일부 Worker가 CORS 정책 때문에 요청을 거부할 수 있습니다. 그럴 때는 별도 GitHub Pages 테스트 폴더에 게시해 보세요. 테스트에서 문제가 없더라도 학교 와이파이·아이패드 Safari의 실제 동작까지 보장하지는 않습니다.

AI API 직접 연결 진단 · v2

먼저 Cloudflare Worker가 실제 AI 응답을 반환하는지 확인합니다. 기존 게임은 로컬 판정·오류 대체 판정만으로도 다음 장면에 넘어갈 수 있어요.

1. 서버에 직접 1건 요청하기

기존 게임에서 다음 대화로 넘어갔다고 반드시 Gemini API가 성공한 것은 아닙니다. 이 페이지는 로컬 판정 없이 실제 API에 직접 요청하므로 연결 문제를 분명히 확인할 수 있습니다.

테스트 버튼을 누르면 실제 AI API 요청이 발생하며 소액의 사용량·비용이 발생할 수 있습니다. 본인이 관리하는 주소에서만 실행하세요. 자동 반복·무한 재시도는 하지 않습니다.

1건 직접 연결에 성공하면 5명, 5명이 모두 정상 응답하면 20명 버튼이 열립니다. 오류가 나면 동시접속 검사는 진행하지 마세요. 자동 재요청은 하지 않습니다.

2. API 실제 응답 결과

아직 테스트하지 않았어요. 위의 동의 체크 후 ‘1명 연결 확인’부터 시작해 주세요.

정상 형식은 SAFE / UNSAFE / RETRY 중 하나를 받은 경우예요. SAFE 개수는 아래 표와 결과 요약에 별도로 표시해요.

오류가 나면 어떻게 확인하나요?

HTTP 502는 Worker 또는 그 뒤쪽 AI 서비스가 정상 응답을 반환하지 못한 상황일 수 있습니다. HTTP 429는 요청 제한이고, 500/503/504도 서버 쪽 오류 가능성이 있습니다. 시간초과는 12초 안에 응답하지 못한 경우입니다. “네트워크/CORS 오류”는 인터넷, Worker 또는 웹페이지 출처 허용 정책과 관련 있을 수 있습니다.

이 페이지를 PC에서 파일로 직접 열어 실행하면 일부 Worker가 CORS 정책 때문에 요청을 거부할 수 있습니다. 그럴 때는 별도 GitHub Pages 테스트 폴더에 게시해 보세요. 테스트에서 문제가 없더라도 학교 와이파이·아이패드 Safari의 실제 동작까지 보장하지는 않습니다.
